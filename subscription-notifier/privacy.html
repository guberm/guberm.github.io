Subscription Notifier Privacy Policy

Effective date: July 3, 2026

Subscription Notifier is a private/internal subscription notification tool operated by Michael Guber for his own Google account. It is not offered to external users.

YouTube and Google user data used

The application uses OAuth with the read-only YouTube Data API scope youtube.readonly. It may access the following data for the authorized account:

  • Subscribed channel IDs and channel titles through youtube.subscriptions.list.
  • Recent activity for subscribed channels through youtube.activities.list.
  • Basic video metadata such as video ID, title, publish date, thumbnail URL, description, and duration through youtube.videos.list.

The application does not request write scopes and does not upload videos, edit metadata, delete content, post comments, rate videos, manage playlists, or modify a YouTube account.

How the data is used

The data is used only to determine whether subscribed channels have published new videos and to send a private email notification to Michael Guber. The application does not sell, rent, share, or transfer API data to third parties.

Storage and retention

The application stores a limited local cache in SQLite on private infrastructure controlled by Michael Guber. Stored fields may include channel ID, channel name, last processed video ID, last video publish date, thumbnail URL, and notification send date. OAuth tokens are stored locally in the Google API client credential store.

The application refreshes data every 10 minutes while the worker is running. It processes only recent channel activity, does not store subscription video-count statistics, and deletes stored video notification metadata older than 30 days.

Data deletion policy

Because this is a private single-user tool, deletion is handled by the operator on request or when the tool is retired. Google user data can be deleted by removing the local SQLite database and OAuth credential store used by the application.

Contact michael@guber.dev to request deletion of stored data.

OAuth revocation and user control

The authorized Google account can revoke access at any time from the Google Account permissions page:

https://myaccount.google.com/permissions

After revocation, the application will no longer be able to access YouTube API data unless OAuth authorization is granted again.

Google Privacy Policy and API Services

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google's privacy policy is available here:

https://policies.google.com/privacy

YouTube API Services terms are available here:

https://developers.google.com/youtube/terms/api-services-terms-of-service

Security

The application runs on private infrastructure controlled by Michael Guber. Access to the server, OAuth credentials, SQLite database, and email configuration is restricted to the operator.
