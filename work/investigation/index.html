The problem

An incident record that can be edited is not a record, and a report that changes every time it is regenerated is not evidence. Most systems only prove that a file exists — not that it is the same file that was written on the night in question.

What it does

  • Append-only incident journal
  • Structured investigations instead of free-form notes
  • Court-ready PDF reports signed with Ed25519
  • Tamper-evident, and byte-identical when regenerated
  • Multi-site RBAC with an oversight dashboard
  • Offline licensing, unlimited users

Runs on your own hardware with zero cloud.Built and maintained by me. Licensed offline, no cloud account needed.
