YTSubsCore Privacy Policy

Effective date: June 1, 2026

YTSubsCore is a private/internal YouTube subscription notification tool operated by Michael Guber for his own Google/YouTube account. It is not offered to external users.

YouTube and Google user data used

YTSubsCore uses OAuth with the read-only YouTube Data API scope youtube.readonly. The application may access the following YouTube data for the authorized account:

  • Subscribed channel IDs and channel titles through youtube.subscriptions.list.
  • Recent activity for subscribed channels through youtube.activities.list.
  • Video metadata such as video ID, title, publish date, thumbnail URL, description, and duration through youtube.videos.list.

YTSubsCore does not request write scopes and does not upload videos, edit metadata, delete content, post comments, rate videos, manage playlists, or modify a YouTube account.

How the data is used

The data is used only to determine whether subscribed channels have published new videos and to send a private email notification to Michael Guber. The application does not sell, rent, share, or transfer YouTube API data to third parties.

Storage and retention

YTSubsCore stores a limited local cache in SQLite on a private Windows/IIS server controlled by Michael Guber. Stored fields may include channel ID, channel name, total video count, last processed video ID, last video publish date, thumbnail URL, and notification send date. OAuth tokens are stored locally in the Google API client credential store.

Data is retained only as long as needed to run the private notification service and avoid duplicate notifications.

Data deletion policy

Because YTSubsCore is a private single-user tool, deletion is handled by the operator on request or when the tool is retired. Google/YouTube data can be deleted by removing the local SQLite database and OAuth credential store used by the application.

Contact michael@guber.dev to request deletion of YTSubsCore stored data.

OAuth revocation and user control

The authorized Google account can revoke YTSubsCore access at any time from the Google Account permissions page:

https://myaccount.google.com/permissions

After revocation, YTSubsCore will no longer be able to access YouTube API data unless OAuth authorization is granted again.

Google Privacy Policy and YouTube API Services

YTSubsCore's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google's own privacy policy is available here:

https://policies.google.com/privacy

YouTube API Services terms are available here:

https://developers.google.com/youtube/terms/api-services-terms-of-service

Security

YTSubsCore runs on private infrastructure controlled by Michael Guber. Access to the server, OAuth credentials, SQLite database, and email configuration is restricted to the operator.
