Internal personal tool - not offered to external users

YTSubsCore watches Michael Guber's own YouTube subscriptions and sends private email notifications.

YTSubsCore uses the YouTube Data API with read-only OAuth authorization to list subscribed channels, check recent channel activity, fetch video metadata/duration, and send email notifications for newly published videos.

The application does not upload videos, modify YouTube data, post comments, rate videos, sell analytics, display ads, or provide a public user-facing product.
